# Evolualog

Site institucional estatico da Evolualog, preparado para publicar no Cloudflare Pages via GitHub.

## Arquivos principais

- `index.html`: estrutura, textos, links e scripts do site.
- `style.css`: visual, responsividade e interacoes.
- `assets/`: logos, favicon e imagens usadas pelo site.

## Publicacao no Cloudflare Pages

Use estas configuracoes ao criar o projeto:

- Framework preset: `None`
- Build command: deixe vazio
- Build output directory: `/`

Depois da primeira publicacao, conecte os dominios personalizados:

- `evolualog.com.br`
- `www.evolualog.com.br`

O subdominio `app.evolualog.com.br` deve continuar apontando para o sistema.
